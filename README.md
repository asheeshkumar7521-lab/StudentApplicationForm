# 🎓 Student Application Form

A responsive and interactive **Student Application Form** built using HTML, CSS, and JavaScript. This project demonstrates form validation, file uploads, user input handling, and dynamic application display.

## 📌 About the Project

The Student Application Form is a frontend web development project designed to collect student admission details through an organized form. JavaScript is used to validate user inputs and display submitted application details dynamically on the webpage.

## ✨ Features

- 🧑 Student name and email input
- 🔐 Password validation
- 🎂 Age and date of birth validation
- ⏰ Preferred interview time selection
- 👤 Gender selection
- 🎓 Course selection
- 🏠 Address input
- 💻 Skills selection using checkboxes
- 📷 Student photo upload with preview
- ✅ Form validation with error messages
- 📋 Dynamic display of submitted applications
- 🗑️ Delete application functionality
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Form structure and input elements
- **CSS3** – Styling and layout
- **JavaScript** – Form validation, event handling, photo preview, and dynamic application cards

## ✅ Form Validation

The application validates important fields before accepting a submission, including:

- Full name
- Email address
- Password strength
- Age and date of birth
- Preferred interview time
- Gender and course selection
- Address and skills
- Student photo file type and size
- Terms and conditions acceptance

Validation errors are displayed near the corresponding form fields to help users correct their input.
